# 课程视频本地存储功能说明

## 功能概述

课程视频现在支持两种存储方式：
1. **腾讯云点播** - 原有的云存储方式
2. **本地服务器** - 新增的本地存储方式

## 使用方法

### 1. 数据库迁移

首先运行数据库迁移：

```bash
cd aibbs-server
rails db:migrate
```

### 2. 管理后台配置

在管理后台编辑课程时，为视频课时选择存储方式：

1. 点击课时旁边的"设置视频"按钮
2. 选择视频存储方式：
   - **腾讯云点播**：使用腾讯云点播服务上传和播放视频
   - **本地服务器**：将视频文件直接上传到服务器本地存储

### 3. 本地视频上传

选择"本地服务器"存储方式后：
- 点击"选择文件"按钮选择本地视频文件
- 支持常见视频格式（MP4、WebM、MOV等）
- 建议文件大小不超过 500MB
- 上传后视频将存储在服务器的 `storage` 目录中

### 4. 视频播放

前端会自动识别视频存储方式：
- **本地视频**：使用 HTML5 `<video>` 标签直接播放
- **腾讯云点播**：使用 TCPlayer 播放器播放

## 技术实现

### 数据库字段

`course_lessons` 表新增字段：
- `video_storage` - 视频存储方式（'local' 或 'vod'）
- `video_filename` - 视频文件名（可选）

### 模型关联

`CourseLesson` 模型新增：
- `has_one_attached :video` - Active Storage 关联
- `local_video?` - 判断是否使用本地视频
- `vod_video?` - 判断是否使用腾讯云点播
- `video_playback_url` - 获取视频播放地址

### 存储位置

本地视频存储在：
```
aibbs-server/storage/
```

## 注意事项

### 1. 存储空间

- 本地存储会占用服务器磁盘空间
- 建议定期清理不需要的视频文件
- 大量视频建议使用腾讯云点播

### 2. 性能考虑

- 本地视频播放会占用服务器带宽
- 对于高并发场景，建议使用腾讯云点播
- 本地存储适合小型应用或开发测试环境

### 3. 安全性

- 本地视频文件通过 Rails 应用提供服务
- 支持权限控制和访问限制
- 建议配置 Nginx/Apache 进行视频文件代理

### 4. 备份

- 本地视频文件需要定期备份
- 建议使用云存储服务进行异地备份

## 配置建议

### 开发环境
- 可以使用本地存储进行开发和测试
- 视频文件较小，不影响开发效率

### 生产环境
- 小型应用：可以使用本地存储
- 中大型应用：建议使用腾讯云点播
- 高并发场景：必须使用腾讯云点播

## 迁移指南

### 从腾讯云点播迁移到本地

1. 在管理后台选择课时
2. 切换存储方式为"本地服务器"
3. 上传本地视频文件
4. 保存后原腾讯云视频不会被自动删除

### 从本地迁移到腾讯云点播

1. 在管理后台选择课时
2. 切换存储方式为"腾讯云点播"
3. 上传视频到腾讯云
4. 保存后本地视频文件不会被自动删除

## 故障排查

### 视频无法播放

1. 检查视频文件是否正确上传
2. 检查视频格式是否支持
3. 检查浏览器是否支持该视频格式
4. 查看浏览器控制台错误信息

### 上传失败

1. 检查服务器磁盘空间
2. 检查文件权限
3. 检查网络连接
4. 查看服务器日志
