# 荣誉榜插件

表彰社区杰出贡献者，每一份付出都值得被看见。

## 功能

- 前台荣誉榜页面展示
- 后台 CRUD 管理（添加/编辑/删除）
- 奖状图片支持（URL + Lightbox 放大查看）
- 自定义排序权重
- 显示/隐藏单条记录
- 前台导航栏入口注入
- 后台导航栏入口注入

## 配置项

| 配置 | 说明 | 默认值 |
|------|------|--------|
| `show_in_nav` | 是否在前台导航栏显示 | true |
| `nav_label` | 导航显示名称 | 荣誉榜 |
| `nav_icon` | Bootstrap Icons 图标类名 | bi-trophy |

## 从核心提取的功能

此插件从 Commun 核心代码中剥离，包含以下组件：
- `HonorsController` — 前台控制器
- `Admin::HonorsController` — 后台管理控制器
- `Honor` 模型（保留在核心，数据库表不变）
- 前台/后台视图
- 荣誉榜 CSS 样式
- 导航栏入口

## 依赖

- 数据库表 `honors`（由核心迁移创建）
- `Honor` 模型（保留在核心 app/models/）
