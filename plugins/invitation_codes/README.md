# 邀请码注册插件

为站点提供注册邀请码功能。

## 功能

- 后台「系统设置 → 邀请码注册」开关 + 自定义提示文案
- 开启后三条注册路径均要求有效邀请码：
  - 邮箱/用户名注册（Web）
  - OAuth 新用户注册（独立邀请码验证页）
  - API v1 注册（`POST /api/v1/auth/register`）
- 后台「邀请码管理」：批量生成（1-100 个）、设置使用次数与过期时间、查看使用进度、删除
- 使用邀请码注册的用户记录关联，可在邀请码详情页查看

## 使用步骤

1. 后台「插件管理」中启用本插件
2. 后台「系统设置 → 邀请码注册」打开开关（可选：自定义邀请码提示文案）
3. 后台「社区 → 邀请码管理」批量生成邀请码
4. 新用户注册时输入有效邀请码即可完成注册

## 实现说明

- 开关唯一入口：`InvitationCode.requirement_enabled?`（插件启用 + 系统设置开启）
- 核心注册流程调用点零修改；插件停用时该 方法恒返回 false，
  注册表单输入框、设置开关、后台入口自动隐藏，已有数据保留
- 数据表 `invitation_codes` 与 `users.invitation_code_id` 列由核心迁移管理
