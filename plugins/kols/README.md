# KOL达人插件

将KOL达人展示与管理功能从核心代码剥离为插件。

## 功能说明
- 前台KOL达人展示页（卡片式布局）
- 后台KOL达人管理（CRUD、Excel批量导入、邮件邀约）
- 前台导航栏入口（可通过插件配置控制）
- 后台导航栏入口

## 配置项
| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| show_in_nav | boolean | true | 是否在前台导航栏显示 |
| nav_name | string | KOL达人 | 导航栏显示名称 |
| nav_icon | string | bi-stars | Bootstrap Icons图标类名 |

## 安装
在后台"插件管理"页面点击"扫描本地"即可自动安装。
